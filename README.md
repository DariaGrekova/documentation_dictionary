# React English Dictionary

Англо-русский словарь для изучения React и чтения англоязычной технической документации.

Проект создан как практический React-проект и учебный полигон: здесь отрабатываются работа с данными, состояние компонентов, передача данных через props, фильтрация, пользовательские взаимодействия, адаптивная вёрстка и работа с модальными окнами.

## Демо

https://documentation-dictionary.vercel.app/

## Цель проекта

Основная идея — собрать в одном месте лексику, которая регулярно встречается в React-документации и технических материалах.

Словарь должен помогать не столько переводить отдельные слова, сколько постепенно привыкать к техническому английскому и узнавать термин в контексте.

Поэтому запись словаря содержит:

- английский термин;
- транскрипцию;
- перевод;
- пример употребления на английском;
- перевод примера;
- категорию.

## Реализованный функционал

### Категории

Слова распределены по тематическим категориям.

Сейчас используются:

- Все слова
- Базовые понятия
- Состояние и данные
- Пропсы и передача данных
- Условный рендер и списки
- Хуки
- Компоненты и композиция
- Архитектура и концепции
- React 19
- Разработка и отладка
- Производительность
- Общетехническая лексика
- Оценочные и модальные слова

Категории имеют собственные `id`, а записи слов ссылаются на категорию через этот `id`.

Например:

```js
{
    id: 1,
    word: "component",
    category: "basics"
}
```

Отображаемое название категории хранится отдельно:

```js
{
    id: "basics",
    label: "Базовые понятия"
}
```

Так данные не дублируют пользовательский текст категории.

### Фильтрация

Выбор категории в Sidebar изменяет состояние `selectedCategory`.

На его основе формируется список отображаемых слов:

```js
const filteredWords = words.filter(
    (word) =>
        selectedCategory === 'all' ||
        word.category === selectedCategory
);
```

### Карточки слов

Каждое слово отображается отдельной интерактивной карточкой.

Карточка содержит:

- термин;
- транскрипцию;
- категорию;
- визуальный индикатор возможности открыть подробности.

### Модальное окно

По клику на карточку открывается модальное окно выбранного слова.

В модальном окне доступны два состояния:

1. пример на английском;
2. перевод и перевод примера.

Между состояниями можно переключаться кнопками.

На мобильных устройствах также поддерживается переключение свайпом.

Модальное окно:

- закрывается кнопкой;
- закрывается по клику на фон;
- закрывается клавишей `Escape`;
- блокирует прокрутку основной страницы на время открытия.

### Адаптивность

Интерфейс адаптирован под desktop и mobile.

На больших экранах Sidebar постоянно отображается слева.

На мобильных устройствах:

- Sidebar открывается через бургер;
- появляется затемнение фона;
- выбор категории закрывает меню;
- прокрутка основной страницы блокируется во время открытия меню;
- карточки становятся компактнее;
- модальное окно адаптируется под размер экрана.

### Количество терминов

Для заголовка категории используется отдельная функция `getWordCountLabel`, которая учитывает русское склонение:

```text
1 термин
2 термина
5 терминов
21 термин
```

## Архитектура

`App` является точкой сборки приложения и хранит основное состояние интерфейса:

```text
App
├── Sidebar
│   └── SidebarItem
│
├── CategoryArea
│
├── WordGrid
│   └── WordCard
│
└── WordModal
```

Основные состояния приложения:

```js
selectedCategory
isOpen
selectedWord
```

### `selectedCategory`

Хранит `id` выбранной категории и используется для фильтрации массива слов.

### `isOpen`

Управляет состоянием мобильного Sidebar.

### `selectedWord`

Хранит выбранное слово либо `null`.

Если слово выбрано, `App` отображает `WordModal` и передаёт ему выбранный объект через prop.

## Данные

На текущем этапе данные слов находятся в:

```text
src/data/words.js
```

Категории находятся в:

```text
src/data/categories.js
```

Запись слова имеет следующую структуру:

```js
{
    id: 1,
    word: "component",
    transcription: "[kəmˈpoʊnənt]",
    translation: "компонент",
    example: {
        en: "React components are JavaScript functions that return markup.",
        ru: "React-компоненты — это JavaScript-функции, которые возвращают разметку."
    },
    category: "basics"
}
```

На текущем этапе данные импортируются непосредственно в приложение:

```js
import { words } from './data/words';
import { categories } from './data/categories';
```

## Работа с состоянием

Состояние реализовано с помощью React `useState`.

Основной поток данных выглядит так:

```text
categories / words
        ↓
      App
        ↓
   filterWords
        ↓
    WordGrid
        ↓
    WordCard
```

При выборе карточки:

```text
WordCard
   ↓ onClick
WordGrid
   ↓ onWordClick
App
   ↓ setSelectedWord
WordModal
```

Так `App` остаётся владельцем состояния выбранного слова, а дочерние компоненты получают необходимые данные и обработчики через props.

## Работа с модальным окном

`WordModal` самостоятельно управляет текущим слайдом:

```js
const [currentSlide, setCurrentSlide] = useState(slides[0]);
```

Для обработки свайпов используются `useRef`, чтобы хранить координаты начала и конца жеста без создания дополнительных рендеров.

Также компонент:

- подписывается на `keydown`;
- удаляет обработчик при размонтировании;
- временно фиксирует `body` для блокировки фоновой прокрутки.

## Текущий этап проекта

На текущем этапе словарь работает с локальным набором данных.

Следующий запланированный этап — отделить данные от приложения и получать словарь из удалённого источника.

Планируемый поток:

```text
Удалённый JSON
      ↓
    fetch
      ↓
   React state
      ↓
 loading / error
      ↓
 фильтрация
      ↓
     UI
```

Этот этап используется как практическое упражнение по работе React с асинхронными данными.
